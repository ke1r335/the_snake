🐍 Snake Game

🌟 Основные возможности

Бесконечное поле: Змейка может проходить сквозь границы экрана, появляясь с противоположной стороны.

Механика роста: При поедании яблока длина змейки увеличивается, а скорость остается комфортной для игры.

Система проигрыша: Игра автоматически перезапускается при столкновении змейки с собственным хвостом.

Библиотека: pygame (графический движок и обработка событий).
